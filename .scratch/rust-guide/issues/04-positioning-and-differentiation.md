# 04 定位与差异化边界

Type: grilling
Status: resolved
Blocked by: 01, 02

## Question

在第 2 轮选定的粗定位（进阶深挖：假定读者基础已过）之上，这本书的承诺被精确到什么程度？

要定下来的：

1. **一句话承诺**：读者读完能做什么（可检验的表述）。
2. **前置假设**：读者必须已经会的（所有权/借用基础、trait、泛型、Cargo）；不满足时怎么办 ——「基础补充盒」的形态。
3. **边界**：明确不写什么（对照 01 的资源版图，避免重复）；与 The Book / Rust 圣经的关系（引用？延伸阅读？）。
4. **差异化论点**：为什么读者选这本而不是官方书 + 现有资料。
5. **读者画像收敛**：是否为「有其他语言经验、但 Rust 只到基础」这一群人；对他们的常见误解（例如把所有权当 GC、把 async 当线程）在定位上如何回应。

产出：定位声明（可直接进书的「前言/读者须知」）+ 边界清单；更新地图 Notes 与（如需）书名候选。

技能：按 grilling 逐轮提问、给推荐答案；用 domain-modeling 收敛本书自己的关键概念与官方术语的对应。

## Answer

定位定稿（2026-10-18）。本票前提被**翻转**：第 2 轮粗定位是「进阶深挖（假定基础已过）」，经 01/02 证据核对后由用户改判为「**从零教程（假定会编程、不假定会 Rust）**」。风险明知并接受：中文入门层已饱和且雷同（01 §1–§2），差异只能落在**讲法** —— 心智模型先行 + 诊断贯穿 + 示例全可编译。

### 定位声明（定稿）

- **读者 / 起点线**：中文读者；会一门主流语言（不限语言）、用过命令行与包管理器、懂函数/类型/错误处理基本概念。不假定会 Rust，也不假定泛型/迭代器/编译期概念 —— 用最小示例 + C++/Java/Python 对照现场建立。不设「基础补充盒」：基础即正文。
- **一句话承诺（主轴 = 理解）**：从零起步，读完能理解 Rust 的设计与底层模型（为什么所有权、借用、生命周期长这样），并能独立写出、维护自己的 Rust 程序；诊断训练（读报错、改对、定位性能/并发问题）贯穿全书，是理解力自然长出的能力。
- **内容范围**：基础篇 → 进阶篇（02 的 13 个主干主题）→ 补充章节（深水 D1–D7 与领域；系统层讲深，含手写集合/别名模型要点）。
- **讲法（正面差异化，不点名任何现有资源）**：① 心智模型先行（先讲为什么，再给规则）② 诊断训练贯穿（从第一章起教读编译器）③ 示例全可编译可验证 ④ 自包含 + 章末延伸阅读。
- **明确不做**：逐章对照/翻译任何现有书；点名或对标任何现有中文资源；深水全谱摊进正文；领域专章（领域进补充章节）。
- **常见误解**：暗线处理（不设专门装置，纠偏融进正文；素材 01 §2.2）。
- **暂名**：《Rust 指南（暂定）》；正式书名仍待定。
