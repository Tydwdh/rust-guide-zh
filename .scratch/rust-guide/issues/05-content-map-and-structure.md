# 05 内容版图与章节结构

Type: grilling
Status: open
Blocked by: 04

## Question

本书的内容版图与章节结构 v0 是什么：部分怎么切、章怎么排、每章边界到哪？

要定下来的：

1. **部分划分**（概念为骨 + 每部分配一个实战项目）：每个部分的范围、目标、实战项目选型（先给候选与判据）。
2. **章节清单**：每章一句话目的 + 依赖关系 + 预估体量（用于后续写作票切分）。
3. **顺序**：依赖序（输入：02 知识结构基线）；哪些可以并行写。
4. **取舍记录**：明确砍掉/推迟的主题及理由。
5. **切片**：把版图切成后续写作票的粒度（每章一张？每部分一张？），并说明每张写作票的「完成」判据（与 06 对齐）。

产出：`src/SUMMARY.md` 的 v0 结构 + 每章一句话说明（先落成仓库内文档）。

技能：grilling + domain-modeling。
