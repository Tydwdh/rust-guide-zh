- **六部分·批次序**：基础篇 → 类型与 trait 主干 → 并发与异步 → 系统层 → 工程实践 → 补充章节（= 02 的批 1→批 5；基础篇吸收了批 0 的约定与 B 层）。

- **粒度与切片**：一个主题一章；**每章一张写作票**；每章末 **2–3 道理解题（带答案）**。
