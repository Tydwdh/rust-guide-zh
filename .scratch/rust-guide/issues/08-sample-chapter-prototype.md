# 08 样板章

Type: prototype
Status: open
Blocked by: 05, 06

## Question

用一章真实的样板，把「05 内容版图」与「06 写作与验收规范」落到纸面：这本书写出来到底是什么手感？

要做的事：

1. 从 05 的章节清单里挑一章最有代表性的（进阶难点 + 需要图示/示例），按 06 的规范写完整一章 —— 可粗，但结构与示例要真。
2. 示例代码真实可编译（或按规范标注），校验链跑通。
3. 交付后请用户按「读起来怎样」反馈：深浅、节奏、示例密度、图示有用性。
4. 把反馈收敛成对 05/06 的修订项；若触发结构性修改，开新票或在原票补记。

产出：`src/` 下样板章 + 反馈纪要；原型里的取舍沉淀回规范。
